# 🌾 Agrimart – Smart Agriculture Price Prediction System

## 📌 Overview
Agrimart is a full-stack web application integrated with Machine Learning that predicts vegetable prices based on historical data.  
It helps farmers, traders, and consumers make better decisions using data-driven insights.

---

## 🚀 Features
- 📊 Predict future vegetable prices using Machine Learning
- 🛒 User-friendly web interface for interaction
- 🔐 Authentication system (Login/Register)
- 📈 Data visualization and reports
- 🌐 REST API integration
- 📁 CSV-based dataset handling

---

## 🧠 Machine Learning
- Model Used: Random Forest Algorithm
- Dataset: Historical vegetable price data
- Output: Predicted future prices
